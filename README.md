# AutoCAD Map Telecom Network Design Framework (AutoLISP)

A comprehensive AutoCAD Map customization framework developed using **AutoLISP** for **FTTB/FTTH Outside Plant (OSP) Telecom Network Design**.

This project was developed for a major telecom operator to simplify and standardize the planning and design of fiber optic networks within AutoCAD Map.

---

## Overview

This framework transforms AutoCAD Map into a telecom engineering application by providing specialized tools for:

- Telecom asset placement
- Fiber splice management
- Fiber connectivity management
- Network tracing
- Engineering validation
- Automatic labeling
- Reporting
- GIS data export

The framework was designed to support the complete engineering workflow required for planning and creating telecom OSP networks before importing them into the enterprise Telecom Inventory / GIS system.

## Background

During the early expansion of FTTB/FTTH networks, engineers were required to manually design telecom networks inside AutoCAD.

This approach had several challenges:

- Time-consuming engineering workflow
- Manual splice management
- Difficult network tracing
- High dependency on experienced CAD operators
- Expensive telecom software licenses
- Inconsistent data quality

To address these challenges, I independently designed and developed a complete AutoCAD customization framework using AutoLISP.

The framework automated many engineering activities while ensuring that telecom engineering standards were consistently followed.

# Major Features

## Model Palette

A dockable engineering palette used for rapid placement of telecom assets.

Supports:

- Buildings
- Manholes
- Handholes
- Pillar Boxes
- Splice Closures
- Fiber Cables
- Copper Cables
- Other Telecom Structures

Features include:

- Automatic object snapping
- Validation during placement
- Automatic attribute population
- Business rule enforcement
- Automatic codification

---

## Connection Editor

Interactive splice connection editor.

Features:

- Automatically detects nearby cables
- Supports single fiber connections
- Supports buffer-level connections
- Displays existing splice information
- Simplifies splice management

---

## Trace Network

Automatically traces fiber connectivity.

Capabilities:

- Forward and reverse tracing
- Connection-based network traversal
- Highlights disconnected cables
- Identifies disconnected splice closures
- Animated network trace visualization

---

## Splice Report

Generates printable HTML reports.

Features:

- Reports for individual splice closures
- Batch report generation
- Suitable for field engineers and technicians
- Easy printing and documentation

---

## Automatic Data Creation

The framework assists engineers during network creation by:

- Auto-populating attribute values
- Applying business rules
- Validating user inputs
- Maintaining network integrity
- Reducing manual work

---

## GIS Export

Supports exporting AutoCAD data into ESRI Shapefile format for GIS integration.
